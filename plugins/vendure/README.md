# Zcash payments for Vendure

A Vendure 3 payment method handler that takes shielded Zcash through your own [zcash-payment-service](https://github.com/nerdcash/zcash-payment-service). No middleman, no fees.

```sh
npm install @nerdcash/vendure-payment-zcash
```

See the [Vendure plugin docs](https://nerdcash.github.io/zcash-payment-service/vendure.html) for setup and testing.
