# Zcash payments for Medusa

A Medusa v2 payment provider that takes shielded Zcash through your own [zcash-payment-service](https://github.com/nerdcash/zcash-payment-service). No middleman, no fees.

```sh
npm install @nerdcash/medusa-payment-zcash
```

See the [Medusa plugin docs](https://nerdcash.github.io/zcash-payment-service/medusa.html) for setup and testing.
